# Reference checklist — re-verify before build and release

This file lists starting official sources and competitors. Claims, prices, plugin versions, Woo lifecycle hooks, marketplace rules and screenshots need live verification when the development agent runs. These are research sources, not test evidence.

## WordPress/WooCommerce references
- WooCommerce CRUD objects: https://developer.woocommerce.com/docs/best-practices/data-management/crud-objects/
- Woo extension compatibility: https://developer.woocommerce.com/docs/best-practices/compatibility/
- Woo Marketplace submission: https://developer.woocommerce.com/docs/woo-marketplace/submitting-your-product/
- Woo extension/QIT resources: https://developer.woocommerce.com/docs/extensions/getting-started-extensions/
- WordPress Plugin Directory: https://developer.wordpress.org/plugins/wordpress-org/
- WordPress readme.txt: https://developer.wordpress.org/plugins/wordpress-org/how-your-readme-txt-works/
- WordPress Plugin Directory developer information: https://wordpress.org/plugins/developers/
- WordPress Playground steps and schema: https://developer.wordpress.org/playground/blueprints/steps/
- WordPress Playground Blueprint bundles: https://developer.wordpress.org/playground/blueprints/bundles/
- Playground for plugin developers: https://developer.wordpress.org/playground/handbook/guides/for-plugin-developers/

## Evidence policy
Do not claim feature gaps unless actually verified. Document official technical behavior by supported WP/Woo version and tested adapter path. No licensing or marketplace acceptance assumptions.
